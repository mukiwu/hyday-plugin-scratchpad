# 便籤 (Scratchpad)

右上角常駐的快速便籤。點 nav bar 上的 📝 icon 就展開一個 textarea。

不是正式筆記，沒有 frontmatter、沒有 tag、不會出現在筆記列表。純粹是「現在想到要記但又不正式」的中介層。

## 用途

- 等下要打的電話號碼
- 朋友推薦的餐廳名字
- 寫到一半但還沒成形的想法
- 螢幕上某段文字想暫存
- TODO list 的草稿

寫好的東西可以一鍵**複製**到剪貼簿，再貼到正式筆記、Slack、信件等。

## 用法

1. **打開**：點右上角 nav bar 的 📝 icon
2. **寫**：直接打字，**500ms 自動保存**到 plugin storage
3. **複製到剪貼簿**：上方「複製」按鈕，整片內容一次帶走
4. **清除**：「清除」按鈕，第一次點變紅色「確定？」，3 秒內再按一次才真的清空（避免誤刪）

關閉 popover 不會清空，下次點開內容還在。

## 資料

存在 plugin 的 `data.json`：

```json
{ "content": "..." }
```

純 plain text，沒有任何結構。

## 權限

- `ui:statusBar` — 在 nav bar 顯示 icon
- `storage` — 存便籤內容
