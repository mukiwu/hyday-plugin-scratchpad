# 便籤 (Scratchpad)

將便條常駐在右上角，可以寫想法、臨時紀錄、待辦.. 等等的隨手記資訊。自動儲存，有需要也可以直接新增到筆記或日記裡。

## 用途

- 等下要打的電話號碼
- 朋友推薦的餐廳名字
- 寫到一半但還沒成形的想法
- 螢幕上某段文字想暫存
- TODO list 的草稿

## 用法

1. **打開**：點右上角 nav bar 的 📝 icon
2. **寫**：直接打字，**500ms 自動保存**到 plugin storage
3. **→ 筆記**：把當下內容開成一篇新筆記，標題自動用當下時間（`便籤 2026-05-08 14:30`），開好後直接跳過去
4. **→ 日記**：把當下內容附加到**今天的日記**底部（自動加 `## HH:mm` 時間戳）。今天還沒寫日記也會自動建立
5. **複製**：整片內容複製到剪貼簿
6. **清除**：兩段式 confirm（第一次點變紅色「確定？」，3 秒內再按一次才真清）

## v1.1.0 變更

- 新增「→ 筆記」「→ 日記」兩個快速送出按鈕，省得手動複製貼上

## 資料

存在 plugin 的 `data.json`：

```json
{ "content": "..." }
```

純 plain text，沒有任何結構。

## 權限

- `ui:statusBar` — 在 nav bar 顯示 icon
- `notes:write` — 新增到筆記 / 附加到日記
- `storage` — 存便籤內容
